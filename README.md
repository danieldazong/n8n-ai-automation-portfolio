# n8n AI Business Automation Portfolio

Hi, I’m Daniel Dazong, an AI Solutions Engineer focused on building practical automations that reduce manual work, improve business operations, and make AI useful inside real workflows.

This repository contains selected automation projects built with n8n, OpenAI, Airtable, Gmail, APIs, and workflow logic.

| Project | Tools | Business Value |

| AI Customer Support Router | n8n, OpenAI, Gmail, Airtable | Classifies, prioritizes, and routes customer support messages |

## Security Notice

All credentials, tokens, private webhook URLs, production IDs, and real customer data have been removed or replaced with placeholders.

## How to Use This Repository

Each project folder contains:

- `README.md` — business explanation and project overview
- `workflow.json` — sanitized n8n workflow placeholder/export file
- `workflow-diagram.png` — add your workflow diagram here
- `screenshots/` — add workflow screenshots
- `sample-data/` — fake sample data for demonstration
- `docs/` — deeper documentation, business problem, workflow breakdown, and testing notes
