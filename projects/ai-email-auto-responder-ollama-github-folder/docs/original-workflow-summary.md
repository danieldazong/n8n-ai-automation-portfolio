# Original Workflow Summary

## Workflow Name

AI Email Auto-Responder (Ollama)

## Node Count

6

## Nodes

- Check Every 5 Minutes
- Get Unread Emails (IMAP)
- 1. Classify Email (Ollama)
- Filter Spam
- 2. Draft Reply (Ollama)
- Prepare Draft for Review

## Main Purpose

This workflow creates an AI-assisted email auto-responder using n8n, IMAP email reading, local Ollama LLM calls, spam filtering, and draft preparation.
