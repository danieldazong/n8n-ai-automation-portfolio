# Workflow Breakdown

## Trigger

The workflow starts when a new form submission, email, webhook, or CRM record is received.

## AI Processing

The AI node extracts, summarizes, classifies, or scores the incoming information.

## Conditional Logic

IF or Switch nodes determine which path the workflow should follow.

## Action

The workflow updates a tracking system, sends a message, creates a task, or notifies the correct person.

## Logging

The workflow records the outcome for traceability and future review.
